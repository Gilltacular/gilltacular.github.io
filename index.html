About

Software Developer

Software developer based in North Houston, TX, with a BS in Computer Science (summa cum laude) from UAT. My path here wasn't traditional — six years as a state law enforcement investigator and five years in IT support shaped how I approach problem-solving: methodically, evidence-first, with an eye for what breaks under pressure.

I build with Python, JavaScript, C++, and PHP, working across web development, database engineering, and security-conscious system design. My capstone project in PLC ladder logic — an automated warehouse sorting system — sparked a deep curiosity for where software meets physical hardware, and I'm actively exploring industrial automation and robotics as growth areas.

I believe code should be resilient, defensive, and honest — the same standards I applied to investigations. Every function should answer for what it does, why it exists, and what happens when it fails.

Currently seeking entry-level software development roles in the Houston metropolitan area. Open to relocation.
